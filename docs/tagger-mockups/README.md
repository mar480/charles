# Tagger mockups

These static HTML files define the initial visual blueprint for the React implementation:

- `project-setup.html`
- `template-entry.html`
- `validation-review.html`

They are intentionally close to the intended product IA:

- setup-first dashboard and wizard
- editable template workspace with right-side inspector
- validation and export review

The React implementation should preserve this structure, information density, and paper-oriented aesthetic while adapting it to the existing component stack.
